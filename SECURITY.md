# Security

Please report security issues privately to **contact@paradoxicalsw.com** with “Stillgarden security” in the subject, or use the repository's private vulnerability-reporting feature if available. Include the affected version, reproduction steps and impact. Do not post credentials or personal data in public issues.

The latest public release is the supported version. This is a small independent project; we cannot promise a response deadline. We will acknowledge actionable reports when possible and coordinate a fix and disclosure with the reporter.

Stillgarden stores local garden/settings data and opens external links only on user action. Release archives include a SHA-256 checksum. The initial release is ad-hoc signed, not Apple-notarized. Source builds are available for inspection and local compilation.
