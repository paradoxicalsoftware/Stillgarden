# A garden worth tending

These are areas we would like to explore, not promised dates.

## Next priorities

- More keyboard and VoiceOver coverage, including planting without a pointer.
- Real-device testing across supported macOS versions and Intel hardware.
- Better performance measurements for densely planted gardens.
- Apple Developer signing and notarization for simpler first launch.
- More botanical detail, thoughtfully sourced natural sound, and seasonal polish.

## Ideas to discuss

- Additional garden scenes with consistent visual quality.
- A simpler way to export and import a garden.
- More control over reduced motion, flashes and sensory intensity.
- Splitting the initial Swift file into focused modules as the project grows.

We aim to keep the core experience offline, understandable and free. Requests are welcome in Issues; contribution discussions should focus on how a change feels to the person using it.
